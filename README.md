# Смета за 5 минут

Веб-приложение, в котором человек быстро собирает смету или коммерческое предложение и сохраняет его в PDF.

Им пользуются:

- предприниматели — чтобы отправить клиенту коммерческое предложение;
- офисные сотрудники — чтобы собрать смету закупки или список расходов для руководителя.

## Файлы

| Файл | За что отвечает |
| --- | --- |
| `index.html` | Страница: подписи, поля, кнопки и структура документа. |
| `styles.css` | Внешний вид: размеры, отступы, читаемость на компьютере и на телефоне. |
| `script.js` | Расчёт сумм, проверка чисел и сохранение сметы в PDF. |

## Как открыть

Дважды щёлкните по `index.html`. Страница откроется в браузере. Устанавливать ничего не нужно.

## Как проверить

Добавьте две строки:

- 2 × 15 000
- 1 × 8 000

Итог должен быть **38 000 ₸**.

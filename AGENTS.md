# Правила для агента

Проект — «Смета за 5 минут»: одна страница в этой папке. Перед любой правкой прочитай текущие файлы.

## Границы работы

- Работай только в этой папке.
- Сначала читай текущие файлы, потом меняй их.
- Делай только ту функцию, которую просит пользователь. Уже работающие части не ломай и не переписывай «заодно».
- Не запускай git и ничего не публикуй без явной просьбы.

## Технологии

- Только обычные HTML, CSS и JavaScript: `index.html`, `styles.css`, `script.js`.
- Без npm, сборщиков, фреймворков и внешних ресурсов (шрифты, библиотеки, CDN, картинки по ссылке).
- Данные пользователя остаются в браузере. Ничего не отправляй в интернет: ни формы, ни запросы, ни аналитику.

## Удобство

- У каждого поля понятная подпись.
- Поля и кнопки не меньше 44px по высоте.
- Сметой можно пользоваться с клавиатуры и на телефоне.

## Деньги

- Суммы показывай с пробелами между тысячами и знаком тенге: `15 000 ₸`.
- Пустое поле и неверное число считай нулём.
- Никогда не показывай `NaN`.
